# ბაზრის მონაცემების წყარო (ADR-003)

განახლდა: 2026-10-30. წინა ვერსიები (Numbeo-ს ოფიციალური API, Eurostat) — git-ის ისტორიაში; პროდუქტიდან ამოღებულია.

## 1. გადაწყვეტილება

| საკითხი | გადაწყვეტა |
| --- | --- |
| წყარო | Numbeo.com-ის გვერდები, მოპოვებული Apify actor-ით **`automation-lab/numbeo-scraper`** |
| სად სრულდება | მხოლოდ Cloudflare Worker-ში (`/api/market`). ბრაუზერი Apify-ს/Numbeo-ს პირდაპირ არ უკავშირდება |
| ავთენტიფიკაცია | `APIFY_TOKEN` — Cloudflare Secret (ლოკალურად `.dev.vars`), `Authorization: Bearer` სათაურით; არასოდეს URL-ში, ლოგში, git-ში, `dist/`-ში ან არქივში (ამოწმებს `tests/providers/no-secrets.test.js`) |
| ქეში | 30 დღე (`MARKET_CACHE_TTL_DAYS`), Workers KV `MARKET_CACHE`; ინდექსები (`rankings`) — ერთი გაშვებით ყველა ქალაქზე |
| გამორთვა | `MARKET_PROVIDER=off` → გვერდზე „ბაზრის მონაცემები გამორთულია“; გამოთვლები უცვლელად მუშაობს |
| ატრიბუცია | „წყარო: Numbeo.com (მოპოვებულია Apify-ის მეშვეობით)“ + ბმული ქალაქის გვერდზე |

## 2. რისკი, რომელიც მომხმარებელმა იცის

- Numbeo-ს გამოყენების პირობები (terms_of_use.jsp) **კრძალავს ავტომატურ მონაცემთა შეგროვებას (scraping) წერილობითი ნებართვის გარეშე** და მონაცემის ხელახალ გავრცელებას სხვა API-ით/საჯარო ნაკადით. მესამე მხარის actor (Apify) ამ პირობებს არ ცვლის და უფლებას არ ქმნის.
- გადაწყვეტილება მიიღო მომხმარებელმა (ADR-003). კოდი ამიტომ: აჩვენებს წყაროს, არ ქმნის საჯარო API-ს (მხოლოდ შიდა ID + EUR/USD), ზღუდავს მოთხოვნებს (rate limit, 30-დღიანი ქეში) და აქვს ერთი ცვლადით გამორთვა.
- Numbeo-ს ოფიციალური API (ფასიანი, Basic 260 USD/თვე 2026-10-29-ის მონაცემით) უფრო სუფთა სამართლებრივი გზაა, მაგრამ საჯარო საიტზე ხელახალი ჩვენებისთვისაც Numbeo-ს თანხმობას საჭიროებს.

## 3. Apify actor — რა ვიცით და რა არა

ამ სამუშაო გარემოდან `api.apify.com` და `apify.com` დაბლოკილია (proxy 403) — ქვემოთ ჩამოთვლილი აღებულია საჯარო აღწერების ვებ-ძიების ამონარიდიდან (2026-10-30) და **ცოცხლად დაუდასტურებელია**.

| საკითხი | ცნობილი | სტატუსი |
| --- | --- | --- |
| Endpoint | `POST https://api.apify.com/v2/acts/automation-lab~numbeo-scraper/run-sync-get-dataset-items` | Apify API დოკ. (ძიება): წარმატება 201, ტანი = dataset items; 300 წმ-ზე მეტი → 408 |
| ავთენტიფიკაცია | `Authorization: Bearer <token>` | ⚠️ ამ სესიაში არ დადასტურდა (Apify-ის საერთო პრაქტიკა) |
| შესავალი | `mode`: `city_prices` / `rankings` / `comparison`; `cities: [...]` (Numbeo-ს დაწერილობით); ვალუტა („Display Currency“, გასაღები სავარაუდოდ `currency`) | ⚠️ გასაღებების ზუსტი სახელები დაუდასტურებელია |
| გამოსავალი (`city_prices`) | სტრიქონები: Category, Item, Price, Currency (სავარაუდოდ city/country) | ⚠️ ადაპტერი იღებს ორივე ფორმას: ჩადგმულს (`prices[]`) და ბრტყელს; გასაღებები ნორმალიზდება |
| გამოსავალი (`rankings`) | Rank, City, Country, Cost of Living, Rent Index, Groceries, Restaurants, … | ⚠️ |
| ფასი | Apify-ის კრედიტებით (actor-ის ტარიფი/გაშვების ღირებულება) | ⚠️ დაუდასტურებელი — მომხმარებელმა უნდა ნახოს თავის ანგარიშზე |
| თარიღი | actor-ის გამოსავალში წყაროს განახლების თარიღი არ ჩანს | `sourceUpdatedAt = null`, ნაჩვენებია მიღების თარიღი |

ერთეულები — ზუსტი სახელით (ჯერ ძველი და ახალი Numbeo დაწერილობა, შემდეგ მხოლოდ ორი პრეფიქსი — „Basic (Electricity“ და „Internet (“): ქირა ცენტრი/გარეუბანი 1 და 3 საძინებელი, კომუნალური 85 მ², ინტერნეტი, იაფი კვება, საშუალო რესტორანი 2 პირზე. სურსათის კალათა = „Markets“ კატეგორიის საშუალო ფასების ზუსტი ჯამი; ფასის არმქონე ერთეული ჯამში არ შედის და აღირიცხება `itemsMissing`-ში (არასოდეს 0-ად).

ქალაქების სახელები: `src/providers/numbeo-city-names.json` — ყველა 81 ლოკაცია, `verified: false`; ვატიკანი → რომი (`nearby-explained`). დაბრუნებული ქალაქი/ვალუტა მოწმდება — შეუსაბამობა → `wrong_city`.

## 4. რა უნდა გადაამოწმოს მომხმარებელმა პირველი რეალური გაშვების შემდეგ

1. `NODE_USE_ENV_PROXY=1 node scripts/live-check-apify.mjs AT-VIENNA US-NEW-YORK` (ხარჯავს კრედიტს: 3 გაშვება).
2. `sources/extracted/apify-sample-shape.json` — გასაღებების სახელები ემთხვევა თუ არა ადაპტერის ნორმალიზაციას (`apify-numbeo-adapter.js` → `extractPriceRows`, `findRanking`); ვალუტის შესავლის გასაღები მუშაობს თუ არა (EUR/USD).
3. ბეჭდური შედეგი: `valid: true`, ქირის 4 მნიშვნელობა არ არის null, `wrong_city` არ არის.
4. თუ ყველაფერი სწორია: `numbeo-city-names.json`-ში შემოწმებულ ქალაქებს `verified: true`, `_meta.status: "verified"`; ადაპტერიდან `output_schema_unverified` გაფრთხილების მოხსნა.
5. Apify-ის ანგარიშზე ერთი გაშვების ღირებულება და თვიური ხარჯის შეფასება (30-დღიანი ქეშით: ≈ ქალაქების რაოდენობა × 2 ვალუტა + 1 rankings / თვეში).

## 5. ხელით შეყვანა

რჩება ოფლაინ ფაილისთვის და წყაროს არქონისას: ხელით ფორმა და ვალიდირებული JSON იმპორტი (`kind: "market-import"`, `schemaVersion: 2`), status „ხელითაა შეყვანილი“. შეყვანილი ქირა `G`-ში მხოლოდ მომხმარებლის ღილაკით გადადის.
