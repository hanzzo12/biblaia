## 2. ყოველთვიური სამივლინებო თანხა (დანართი №1, მუხლი 3)

წყაროს ციტატა (დ1 მ.3, გვ.10–11):
> ა) გრძელვადიანი სამუშაო მივლინების ყოველთვიური განაკვეთი (S), თვის კალენდარულ დღეთა რაოდენობის გათვალისწინებით, გაიანგარიშება ფორმულით: S = D + (– T + F)
> ბ) … D = (H x A x K ) x (100+C x Q )% … C – ოჯახის წევრთა რაოდენობა; Q – ოჯახის თითოეულ წევრზე პროცენტული დანამატი (Q = 7).
> გ) … T=DxE … E – ბინის ქირის ხვედრითი წილი პროცენტებში.

### R-D-001 — პერსონალური განაკვეთი D
- აღწერა: D = (H × A × K) × (100 + C × Q)%.
- წინაპირობა: H (R-H-001), A (R-POS-*), K (R-K-001), C (R-D-C), Q = 7.
- ფორმულა (A პროცენტით, ერთხელ გადაყვანა): `D = H × (A/100) × K × (100 + 7·C)/100`
- გამონაკლისი: A ან K უცნობი → D დაუდგენელია (არა 0).
- წყარო: დ1 მ.3(ბ) (გვ.10–11).
- სტატუსი: `direct-quote` (ჩანაწერი „x … %“ ნიშნავს A-ს პროცენტად აღქმას და (100+7C)%-ს — ნოტაციის წაკითხვა ცალსახაა).
- ტესტები: T-D-01 (ვენა: 3100×0.65×2.06×1.14 = 4732.026), T-D-02 (C=0 → H×A×K), T-D-03 (A-ს ორჯერ გაყოფის დაცვა).

### R-D-C — C-ის დათვლა
- აღწერა: C = იმ ოჯახის წევრთა რაოდენობა, რომლებზეც კონკრეტულ დღეს/პერიოდში დანამატის უფლება არსებობს; მოსამსახურე არ ითვლება.

### R-FAM-SAMEPOST — ოჯახის ორი წევრი ერთ დაწესებულებაში (მ.4(1))
- ციტატა: „…ერთსა და იმავე დიპლომატიურ წარმომადგენლობასა ან საკონსულო დაწესებულებაში ოჯახის ორი ან მეტი წევრის როტაციის წესით სამუშაო მივლინების შემთხვევაში ოჯახის სხვა წევრებზე დანამატს მიიღებს მხოლოდ ის, რომელიც … №2 დანართით … უფრო მაღალ კატეგორიას განეკუთვნება, ხოლო ბინის დაქირავება უნდა განახორციელოს მათ შორის ერთ-ერთმა.“
- ფორმულა: მაღალი კატეგორიის მოსამსახურისთვის C = სხვა (არამოსამსახურე) წევრები; მეორესთვის C = 0. ქირა (G>0) — მხოლოდ ერთ-ერთს; მეორეს G = 0 (`interpretation`).
- გამონაკლისი: თანაბარი კატეგორია; №3 რეჟიმი — ტექსტში არ არის (OQ-12).
- წყარო: დ1 მ.4(1) (გვ.11). სტატუსი: `direct-quote` + `interpretation` (ქირის განაწილების შედეგი).
- ტესტები: T-FAM-01, T-FAM-02.

### R-FAM-DIFFCITY — სხვადასხვა ქვეყანა/ქალაქი (მ.4(2))
- ციტატა: „…მეუღლეზე პროცენტული დანამატი არ გაიცემა, ხოლო ოჯახის სხვა წევრებზე დანამატს მიიღებს ერთ-ერთი მოსამსახურე ოჯახის წევრების რაოდენობის შესახებ განცხადების საფუძველზე.“
- ფორმულა: მეუღლე-მოსამსახურე C-ში არ ითვლება არც ერთთან; სხვა წევრები — მხოლოდ განცხადებაში მითითებულ ერთ მოსამსახურესთან.
- წყარო: დ1 მ.4(2). სტატუსი: `direct-quote`. ტესტები: T-FAM-03.

### R-FAM-EMPLOYED — დასაქმებული ოჯახის წევრი (მ.4(3))
- ციტატა: „…დანამატი არ გაიცემა მოსამსახურის იმ ოჯახის წევრზე, რომელიც ამავდროულად არის ამავე ან ადგილსამყოფელ ქალაქში არსებული სხვა დიპლომატიური წარმომადგენლობის ან საკონსულო დაწესებულების: ა) მოსამსახურე; ბ) … სხვა საჯარო დაწესებულებიდან ამავე ქალაქში სამუშაოდ მივლინებული პირი.“
- ფორმულა: ასეთი წევრი C-ში არ ითვლება (იმ დღეებში, როცა პირობა მოქმედებს).
- წყარო: დ1 მ.4(3). სტატუსი: `direct-quote`. ტესტები: T-FAM-04.

### R-FAM-OTHERAGENCY — სხვა უწყების მოსამსახურე ოჯახის წევრები (მ.4(4))
- ციტატა: „…ამ ბრძანებით გათვალისწინებული ხარჯები, გარდა გრძელვადიანი სამუშაო მივლინების თანხისა, უნაზღაურდებათ მხოლოდ იმ შემთხვევაში, თუ შესაბამისი დაწესებულების მიერ არ ხდება იგივე სახის ხარჯების ანაზღაურება.“
- ფორმულა: ყოველი არამივლინებითი ხარჯისთვის (მგზავრობა, ბარგი, დაზღვევა, განათლება, მოწყობა, მაკლერი…) კითხვა „ანაზღაურებს სხვა უწყება?“: კი → 0; უცნობი → დაუდგენელი.
- წყარო: დ1 მ.4(4). სტატუსი: `direct-quote`. ტესტები: T-FAM-05.

### R-FAM-DEPENDENT-PRESENCE — მხარდაჭერის მიმღები / მეურვეობის-მზრუნველობის ქვეშ მყოფი (მ.4, მეორე „6“)
- ციტატა: „6. ამ ბრძანებით მოსამსახურის ოჯახის წევრისათვის გათვალისწინებული პროცენტული დანამატი მხარდაჭერის მიმღების, მეურვეობის/მზრუნველობის ქვეშ მყოფი პირების შემთხვევაში გაიცემა მხოლოდ მათი ადგილსამყოფელ ქვეყანაში ყოფნის პერიოდში, გამგზავრებისა და უკან დაბრუნების დღეების ჩათვლით.“ (ციტატა №01-608, 15.12.2023)
- ფორმულა: ასეთი წევრი C-ში ითვლება მხოლოდ ყოფნის დღეებში [ჩამოსვლის დღე … გამგზავრების დღე] ჩათვლით; თვე იყოფა სეგმენტებად (R-PRORATE-001).
- გამონაკლისი: პუნქტის ნომერი „6“ მუხლში ორჯერაა (OQ-06); შინაარსი დამოუკიდებელია.
- წყარო: დ1 მ.4, მეორე „6“ (გვ.12). სტატუსი: `direct-quote`.
- ტესტები: T-FAM-06 (10 დღე ქვეყანაში 30-დღიან თვეში), T-FAM-07 (ჩამოსვლის/წასვლის დღე ჩათვლით), T-FAM-08 (ყოფნის თარიღი უცნობი → C დაუდგენელი).

### R-FAM-ROLES — ოჯახის წევრის სტატუსები
- აღწერა: ოჯახის წევრზე ინახება: როლი (მეუღლე, შვილი, გერი, სხვა), სტატუსი „მხარდაჭერის მიმღები“ და „მეურვეობის/მზრუნველობის ქვეშ მყოფი“ (ორი ცალკე ნიშანი), დაბადების თარიღი/ასაკი (ცარიელი ≠ 0), ქვეყანაში ყოფნის პერიოდები, დასაქმება მისიაში/სხვა უწყებიდან მივლინება, სხვა უწყებიდან ანაზღაურების ფაქტი, ზოგადსაგანმანათლებლო სწავლა/ადგილსამყოფელი სახელმწიფოს თანხმობა (შენიშვნა). სახელი არასავალდებულოა.
- უფლების წყაროები განსხვავდება: 7%-იანი დანამატი (დ1 მ.3–4), მოწყობის 10% (პ.7), დაზღვევა (პ.30), შვებულების ბილეთები (პ.12ბ/გ), განათლება (პ.31–36, შენიშვნა).
- სტატუსი: `interpretation` (სტრუქტურა) / `technical-policy`. ტესტები: T-FAM-09 (მოწყობის რაოდენობა ≠ C).

### R-POS-A3 — დანართი №3 რეჟიმი (ცენტრალური აპარატი) და პ.37–39

### R-POS-20-1 — მოვალეობის შემსრულებელი ხელმძღვანელი

### R-SETTLE-001 — ფორმულა
- ციტატა: „…პირველადი მოწყობის ხარჯები, რომელიც გაიცემა ერთჯერადი დახმარების სახით … №211 დადგენილების №1 დანართით განსაზღვრული ქვეყნის ფარგლებს გარეთ მოკლევადიანი სამსახურებრივი მივლინების დროს უცხოური ვალუტით ანაზღაურების შესაბამისი სადღეღამისო ნორმის სამოცმაგი ოდენობით, ასევე თითოეული ოჯახის წევრზე (გარდა მხარდაჭერის მიმღებისა და მეურვეობის/მზრუნველობის ქვეშ მყოფი პირებისა) დამატებით – ამ პუნქტით გათვალისწინებული ოდენობის 10%.“ (№01-110, 15.03.2024)

- გამონაკლისი: n ≠ C (7%-ის დანამატის რაოდენობა). პ.9 გამორიცხვები. „10% ამ პუნქტით გათვალისწინებული ოდენობის“ — 60-მაგი ნორმის 10% (`interpretation`, ტექსტის ბუნებრივი წაკითხვა; ჯაჭვური ზრდა არ არის).
- წყარო: პ.7 (გვ.4). სტატუსი: `direct-quote` + `interpretation` (10%-ის ბაზა; უნდა ახლდეს თუ არა წევრი ფაქტობრივად — OQ-17).

### R-EDU-SCOPE — დასაშვები ხარჯის შემადგენლობა (პ.31)
- ციტატა: „…ოჯახის არასრულწლოვანი წევრების ადრეული და სკოლამდელი აღზრდა-განათლებისა და ზოგადსაგანმანათლებლო დაწესებულებაში/სკოლაში განათლების მიღებასთან დაკავშირებული ხარჯები, რომლებიც მოიცავს მხოლოდ სწავლის, სასწავლო დაწესებულებაში რეგისტრაციის, ტრანსპორტირებისა (საცხოვრებელი ადგილიდან სასწავლო დაწესებულებამდე და … უკან) და სასწავლო დაწესებულებაში კვების საფასურს.“
- ფორმულა: `P = tuition + registration(monthly share, OQ-03) + transport + meals`; სხვა (წიგნები, ფორმა, ექსკურსია, უმაღლესი განათლება) → არ შედის.
- წყარო: პ.31 (გვ.7). სტატუსი: `direct-quote`. ტესტები: T-EDU-05 (არადასაშვები კატეგორია P-ში არ შედის).

### R-EDU-LIMIT — თვიური ზღვარი (პ.32)
- ციტატა: „…ანაზღაურებას ექვემდებარება სასწავლო წლის დაწყებიდან მის დასრულებამდე პერიოდისთვის, შემდეგი ოდენობის ფარგლებში: ა) … ევროში დაფინანსების შემთხვევაში – თვეში არაუმეტეს 690 ევრო; ბ) … აშშ დოლარში დაფინანსების შემთხვევაში – თვეში არაუმეტეს 750 აშშ დოლარი.“ (№01-485, 02.10.2023)
- ფორმულა: `L = 690 EUR | 750 USD` დაწესებულების დაფინანსების ვალუტით (R-CUR-001); მხოლოდ სასწავლო წლის თვეებში.
- გამონაკლისი: ზღვარი თითო ბავშვზეა თუ ოჯახზე — ტექსტი მრავლობითში საუბრობს („წევრების … ხარჯები … თვეში არაუმეტეს“) → **OQ-02**. დროებითი მიდგომა: თითო ბავშვზე (`interpretation`, ძველი HTML-ისა და დავალების ეტალონების შესაბამისად), ყოველთვის გაფრთხილებით „ერთ ბავშვზე გამოყენება დასადასტურებელია“; რამდენიმე ბავშვის შემთხვევაში ალტერნატიული (ოჯახის ერთი ზღვრის) შედეგიც ჩანს სცენარად.
- წყარო: პ.32 (გვ.7–8). სტატუსი: `direct-quote` (L) + `interpretation` (გამოყენების ერთეული).
- ტესტები: T-EDU-01 (P=1000 EUR → 938), T-EDU-02 (P=1000 USD → 950), T-EDU-03 (P=0 → 0; P=L → L), T-EDU-04 (ორი ბავშვი — ორივე სცენარი), T-EDU-06 (ზაფხულის თვე სასწავლო წლის გარეთ).

### R-EDU-EXCESS — ზღვარს ზემოთ 80% (პ.33)
- ციტატა: „თუ … ხარჯები აღემატება ამ ბრძანების 32-ე პუნქტის ,,ა“ და ,,ბ“ ქვეპუნქტებით გათვალისწინებულ ოდენობას, ასევე ანაზღაურდება განათლების მიღებასთან დაკავშირებულ ხარჯსა და ყოველთვიურ ლიმიტს შორის სხვაობის 80%.“ (№01-342, 07.04.2025)
- ფორმულა: `eduReimb = min(P, L) + 0.80 × max(P − L, 0)`; `personalEdu = P − eduReimb`. 80%-იან ნაწილს ზედა ზღვარი ტექსტში არ აქვს.
- წყარო: პ.33 (გვ.8). სტატუსი: `direct-quote`. ამოქმედების თარიღი უცნობია (გამოქვ. 08.04.2025) — ადრინდელი პერიოდისთვის წესი შეიძლება განსხვავდებოდეს (R-EFF-001).
- ტესტები: T-EDU-01, T-EDU-02, T-VIENNA-02 (ნაშთი ქირისა და განათლების შემდეგ = S + 938 − 1500 − 1000 = 3423.16).

### R-EDU-SPECIAL — მინისტრის გადაწყვეტილება (პ.34, პ.36-ის ბოლო წინადადება)
- აღწერა: განსაკუთრებულ შემთხვევაში განსხვავებული წესი (33-ე/36-ე პუნქტისგან). ხელით, ნიშნით; ავტომატური არ არის. სტატუსი: `direct-quote`; `conditional-manual`. ტესტები: T-EDU-07.

### R-EDU-HOLIDAY — არდადეგების დამატებითი ხელშეკრულება (პ.35)
- ციტატა: „არდადეგების პერიოდში (ზამთრის და ზაფხულის) … დამატებით დადებული ხელშეკრულების საფუძველზე განათლების მიღებასთან დაკავშირებული ხარჯები ანაზღაურებას არ ექვემდებარება.“
- ფორმულა: ასეთი ხარჯი P-ში არ შედის (reimb = 0). სტატუსი: `direct-quote`. ტესტები: T-EDU-08.

### R-EDU-FREESTATE — სახელმწიფო ენაზე უფასო სკოლა (პ.36)
- ციტატა: „…იმ ქალაქში, სადაც განთავსებულია … დაწესებულება, სახელმწიფო ენაზე უფასო სასწავლებლის არსებობის შემთხვევაში, … არ აუნაზღაურდება ოჯახის არასრულწლოვანი წევრების ამავე ენაზე ფასიან სასწავლებელში განათლების მიღებასთან დაკავშირებული ხარჯი.“
- ფორმულა: კითხვები: „ქალაქში არის სახელმწიფო ენაზე უფასო სასწავლებელი?“ და „ფასიანი სასწავლებლის სწავლების ენა იგივეა?“ — ორივე კი → reimb = 0; უცნობი → დაუდგენელი. „სახელმწიფო ენის“ მნიშვნელობა — OQ-20.
- სტატუსი: `direct-quote` + `interpretation`. ტესტები: T-EDU-09.

### R-EDU-ADULT — სრულწლოვანი შვილი/გერი (შენიშვნა)
- ციტატა: „შენიშვნა: ამ ბრძანების მიზნებისთვის, მოსამსახურის ოჯახის არასრულწლოვან წევრში აგრეთვე მოიაზრება ადგილსამყოფელი სახელმწიფოს თანხმობით, ზოგადსაგანმანათლებლო დაწესებულებაში/სკოლაში განათლების მიღების დასრულებამდე – სრულწლოვანი შვილი/გერი, სრულწლოვანების მიღწევიდან არაუმეტეს 1 წლის განმავლობაში.“ (№01-8, 18.01.2019)
- ფორმულა: `eligibleMinor(child, day) = age < 18 OR (role ∈ {შვილი, გერი} AND hostStateConsent AND inGeneralEducation AND day < 18th birthday + 1 year AND day ≤ educationEndDate)`.
- გამონაკლისი: ვრცელდება ყველგან, სადაც ბრძანება „არასრულწლოვან წევრს“ ახსენებს (პ.31–36, პ.28). 7%-იან დანამატსა და დაზღვევაზე პირდაპირ კავშირი არ აქვს (OQ-22).
- წყარო: შენიშვნა (გვ.8). სტატუსი: `direct-quote` + `interpretation` (სრულწლოვნების ასაკი 18 — მოწოდებულ ტექსტში არ არის, ზოგადი სამართლიდან).
- ტესტები: T-EDU-10 (18 წ. + 11 თვე, თანხმობით → უფლებამოსილი), T-EDU-11 (18 წ. + 1 წ. + 1 დღე → არა), T-EDU-12 (თანხმობა უცნობი → დაუდგენელი).
