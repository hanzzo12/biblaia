# არქიტექტურული გადაწყვეტილება (ADR-001)

სტატუსი: მიღებულია ხელმძღვანელის მიერ, პირველი ეტაპი. თარიღი: 2026-10-29.

## კონტექსტი

- სამართლებრივი წყარო: `sources/original/rotation_sources.pdf` — ბრძანება №01-82 და დანართები №1–10 ერთ გაერთიანებულ სამუშაო ასლად (34 გვ., შედგენილია 2026-10-28). ცალკეული `.doc` ფაილები, რომლებიც დავალებაშია ჩამოთვლილი, არ მოგვეწოდა — მხოლოდ ეს PDF.
- პროტოტიპი: `sources/legacy/rotation_calculator_v7_11.html` (შესადარებელი კოდი, არა წყარო).

## გადაწყვეტილება

1. **ერთი გამოთვლის ბირთვი** — `src/core/` სუფთა ES-მოდულები (JavaScript + JSDoc), DOM/ქსელის გარეშე. თანხები ზუსტი რაციონალური არითმეტიკით (BigInt წილადები); დამრგვალება მხოლოდ ჩვენებისას (ტექნიკური პოლიტიკა, არა ნორმა).
2. **ერთი ნორმატიული მონაცემთა ფაილი** — `src/data/normative-data.json`, რიცხვები ათწილად სტრიქონებად; ნედლი ამონაწერები `sources/extracted/`-ში. UI მონაცემებს ხელით არ აკოპირებს — build ჩასვამს.
3. **ერთფაილიანი ოფლაინ გამოშვება** — `dist/rotation-calculator.html`: esbuild-ით შეკრული IIFE + CSS + ჩაშენებული ქართული ფონტი (Noto Sans Georgian, OFL) + ნორმატიული მონაცემები. გარე CDN არ გამოიყენება. PDF — ბრაუზერის „ბეჭდვა → PDF-ად შენახვა“ ბეჭდვის CSS-ით (ტექსტური, არა სურათი).
4. **ბაზრის მონაცემები (ქირა/ინდექსი)** — ოფლაინ ფაილში: ხელით შეყვანა და ვალიდირებული JSON იმპორტი. ავტომატური მონაცემი საჭიროებს საიდუმლო გასაღებიან ფასიან API-ს (Numbeo), რომლის გასაღები ბრაუზერში ვერ დაიმალება → **სერვერული ნაწილი საჭიროა მხოლოდ ამისთვის**.
5. **ონლაინ ვარიანტი** — Cloudflare Workers Static Assets: იგივე HTML (`dist/web/index.html`) + Worker `worker/index.js` მარშრუტით `GET /api/market?location=<შიდა ID>&currency=<EUR|USD>`. გასაღები — Cloudflare Secret. ფინანსური გაანგარიშება რჩება ბრაუზერში; Worker-ს მხოლოდ ქალაქის ID და ვალუტა მიდის.
6. **ტესტები** — `node --test` (unit/მონაცემები/ადაპტერი/Worker), Playwright (ბრაუზერი, `file://`, ოფლაინ).
7. **დამოკიდებულებები** — მხოლოდ dev: `esbuild`, `wrangler`, `playwright`. React/Next/D1 არ გამოიყენება.

# ADR-002 — აუდიტორია: საჯარო, უფასო, პირადი გამოყენების გვერდი

სტატუსი: მიღებულია 2026-10-29 მომხმარებლის განმარტების საფუძველზე („სამინისტროს შიდა გამოყენებისთვის არ არის; საჯარო, ნორმატიული აქტის მიხედვით შედგენილი გვერდი, პირადი გამოყენებისთვის, უფასო“). ცვლის ADR-001-ის მე-4/მე-5 პუნქტს ბაზრის მონაცემების ნაწილში.

1. **Numbeo API არ გამოიყენება.** ის ფასიანია, ხოლო საჯარო საიტზე მისი მონაცემების ხელახალი ჩვენება/გავრცელება Numbeo-ს თანხმობას მოითხოვს. ადაპტერის კოდი რჩება გამორთულ, არანაგულისხმევ მოდულად (`PROVIDER=numbeo` მხოლოდ ლიცენზიის შემთხვევაში), მაგრამ საჯარო განთავსების ინსტრუქცია მას არ რთავს.
2. **ქირა** — ხელით შეყვანა და ვალიდირებული JSON იმპორტი; ქალაქის გარე ბმულები („ნახეთ Numbeo-ზე“) — მხოლოდ ჰიპერბმული, მონაცემის წამოღების გარეშე.
3. **ცხოვრების ღირებულების ინდექსი** — Eurostat-ის ოფიციალური კორექტირების კოეფიციენტები (ბრიუსელი = 100; `prc_colc_ext` ევროკავშირის გარეთ, `prc_colc_nat` ევროკავშირში). უფასოა, ხელახალი გამოყენება დაშვებულია წყაროს მითითებით (Commission Decision 2011/833/EU, CC BY 4.0) და პასუხისმგებლობის უარყოფის ტექსტით. ეს არ არის ქირის თანხა და არ ცვლის ბრძანების K-ს.
4. **Worker** — საიდუმლო გასაღები აღარ სჭირდება; `/api/market` ემსახურება Eurostat-ს (შეზღუდული პარამეტრები, rate limit, ნებადართული ქეში). Cloudflare Access საჯარო გვერდისთვის საჭირო არ არის.
5. **ოფლაინ HTML** — Eurostat-ის დათარიღებული ასლის ჩაშენება დასაშვებია (ლიცენზია ამის უფლებას იძლევა) და ჩანს როგორც „შენახული ასლი, თარიღით“, არა live. ასლის შესაქმნელად საჭიროა ქსელური წვდომა `ec.europa.eu`-ზე, რომელიც ამ სამუშაო გარემოში დაბლოკილია — მანამდე ასლი ცარიელია და მომხმარებელს ხელით/JSON იმპორტი რჩება.
