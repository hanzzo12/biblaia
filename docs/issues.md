## ISS-001 — `node --test <საქაღალდე>/` Node 22-ზე ჩავარდება

- **სად:** `package.json` → `"test": "node --test tests/unit/ tests/data/ tests/providers/ tests/worker/"` და `"test:e2e": "node --test tests/e2e/"`.
- **მტკიცებულება:** `node --test tests/data/` (Node v22.22.0) აბრუნებს `Error: Cannot find module '/home/user/biblaia/tests/data'` და `fail 1` შედეგს, არცერთი ტესტი არ სრულდება. Node 22-ში პოზიციური არგუმენტი glob-ია და საქაღალდის რეკურსიული ძებნა აღარ ხდება.
- **შემოთავაზება:** გამოიყენეთ glob, მაგ. `node --test "tests/unit/**/*.test.js" "tests/data/*.test.js" …`. ბრჭყალები საჭიროა, რომ შაბლონი Node-მა გაშალოს.
- **ჩემი ტესტები:** `node --test "tests/data/*.test.js"` → 22 ტესტიდან 22 გადის.
- ფაილი ხელმძღვანელისაა; მე არ შემიცვლია.

## ISS-002 — ნორმატიული მონაცემები და დამოუკიდებელი ეტალონი

რა გადამოწმდა:
- K/E: 25 სტრიქონი, მათ შორის ირანი 1.89/24.
- დაზღვევა: 27 სრული სტრიქონი, 12-ვე ჯგუფით. ოდესა 734 და კიევი 1137 (40–44) ცალ-ცალკე სტრიქონზეა.
- ბარგი: 21 ჩანაწერი, მათ შორის ლიონი 1950.
- 16 დაწესებულების დაზღვევისა და ბარგის კავშირი.
- რაოდენობები: 82 დაწესებულება (44 + 38), №4-ში 69 სტრიქონი.
- წყაროს ანომალიები შენარჩუნებულია „შეუსწორებლად“: სტოკჰოლმი, ჰელსინკი, რიადი, რუსეთის სექცია.
- დონეცკის ორჯერ დაბეჭდილი სტრიქონი ერთ უფლებად ითვლება.

- სერბეთი, მიუნხენი და მონტენეგრო დაწესებულებად არ არის შეტანილი.
- ყველა ნორმატიული რიცხვი დადებითი ათწილადი სტრიქონია; `"0"` არსად არ არის.
