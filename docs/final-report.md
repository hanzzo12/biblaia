## ბაზრის მონაცემები

- არჩეული: Apify `automation-lab/numbeo-scraper` (თქვენი მითითებით), მხოლოდ Worker-იდან; ტოკენი — Cloudflare Secret. **რეალურად შემოწმდა** ვენა (EUR) და ვაშინგტონი (USD); ინდექსები — 547 ქალაქი.
- ღირებულება: ≈ $2.75/თვე ინდექსებზე + $0.015 ქალაქზე 30 დღეში (≤ $1.22 81 ქალაქზე).
- რისკი: Numbeo-ს პირობები კრძალავს scraping-ს და ხელახალ გავრცელებას; გამორთვა — `MARKET_PROVIDER=off`.

## ჩასართავად საჭიროა (თქვენი მხრიდან)

1. Cloudflare-ის ანგარიში → `npx wrangler login`.
2. `npx wrangler kv namespace create MARKET_CACHE` → id `wrangler.jsonc`-ში.
3. `npx wrangler secret put APIFY_TOKEN` (რეკომენდებულია ახალი ტოკენი — ძველი ჩატში გამოჩნდა).
4. `npm run deploy`.
