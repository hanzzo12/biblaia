# ღია სამართლებრივი საკითხები

საფუძველი: მოწოდებული რედაქცია (`sources/original/rotation_sources.pdf`). ყოველ საკითხზე: რატომ არის მნიშვნელოვანი (ცვლის თუ არა თანხას), აპის დროებითი მიდგომა (არასდროს — ჩუმი ვარაუდი) და ვინ უნდა გადაწყვიტოს.

„გადამწყვეტი“ აღნიშვნები: **ფინ.** — სამინისტროს ფინანსური სამსახური (ფინანსების მართვის დეპარტამენტი ან შესაბამისი); **იურ.** — იურიდიული დეპარტამენტი; **HR** — ადამიანური რესურსების სამსახური; **ხელმძღ.** — პროექტის ხელმძღვანელი (ტექნიკური პოლიტიკა). ზუსტ სტრუქტურულ ერთეულს ადგენს დამკვეთი.
