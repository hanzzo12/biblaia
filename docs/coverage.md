# პუნქტების დაფარვის სია — ბრძანება №01-82 და დანართი №1

წყარო: `sources/original/rotation_sources.pdf` (მოწოდებული რედაქცია). წესების დეტალი — `docs/rules.md`.

კლასიფიკაცია:

- `auto-calc` — კალკულატორი თვითონ ითვლის შეყვანილი პარამეტრებიდან.
- `conditional-manual` — მომხმარებელი შეიყვანს ფაქტობრივ თანხას/პირობას/გადაწყვეტილებას; კალკულატორი ამოწმებს ზღვარს და პირობებს, უფლებას checkbox-ით არ ანიჭებს.
- `informational` — ჩანს წესად/შეტყობინებად, თანხას არ ითვლის.
- `not-calculation` — თანხასთან კავშირი არ აქვს.
