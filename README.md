# დიპლომატიური როტაციის კალკულატორი

საჯარო, უფასო, ქართულენოვანი კალკულატორი, რომელიც საქართველოს საგარეო საქმეთა მინისტრის **ბრძანება №01-82**-ისა და მისი №1–10 დანართების მიხედვით ითვლის როტაციის წესით გრძელვადიანი სამუშაო მივლინების თანხას და დაკავშირებულ ხარჯებს. ქალაქის არჩევისას იქვე ჩანს ქირისა და ცხოვრების ღირებულების საორიენტაციო მონაცემები (Numbeo.com, Apify-ის მეშვეობით).

> ⚠️ გაანგარიშება საინფორმაციოა. ოფიციალურ თანხას ადგენს შესაბამისი ადმინისტრაციული აქტი. აგენტების გუნდის მიერ ჩაწერილი სამართლებრივი ინტერპრეტაციები (მონიშნულია „სცენარად“ და `docs/open-questions.md`-ში) უწყებრივად დამტკიცებული არ არის.

## როგორ გავხსნა

| ვარიანტი | რა ხდება | ბაზრის ფასები |
| --- | --- | --- |
| **ონლაინ (ძირითადი)** — Cloudflare-ზე განთავსებული გვერდი | სრული კალკულატორი + ქირა/კომუნალური/სურსათი/რესტორნები + 5 ქალაქის შედარება | ✅ (Worker → Apify → Numbeo, 30-დღიანი ქეში) |
| **ოფლაინ ფაილი** — `release/rotation-calculator.html` ორმაგი დაწკაპუნებით | ყველა ოფიციალური გამოთვლა ინტერნეტის გარეშე | ❌ (ფაილს სერვერი არ აქვს) |

განთავსება — ნაბიჯ-ნაბიჯ: **[docs/deploy.md](docs/deploy.md)**. მოკლედ:

```bash
npm ci
npm test && npm run test:e2e
npx wrangler login
npx wrangler kv namespace create MARKET_CACHE   # დაბეჭდილი id → wrangler.jsonc (REPLACE_WITH_KV_NAMESPACE_ID)
npx wrangler secret put APIFY_TOKEN             # ტოკენს ბრძანება თავად გკითხავთ; კოდში არასოდეს ჩაწეროთ
npm run deploy:dry                              # შემოწმება ატვირთვის გარეშე
npm run deploy
```

ლოკალურად: `.dev.vars.example` → `.dev.vars` (ჩაწერეთ `APIFY_TOKEN`), შემდეგ `npm run dev` და გახსენით http://localhost:8787.

## რას ითვლის

- **ყოველთვიური სამივლინებო თანხა** `S = D − T + F`, სადაც `D = H × A × K × (1 + 0.07 × C)`, `T = D × E`, ქირის სუბსიდია `F` — დანართი №1, მუხლი 3 (ხელმძღვანელი: სხვაობის 80%, დამატება ≤ 2T; სხვები: 50%, დამატება ≤ T).
- თანამდებობის ორი რეჟიმი: დანართი №2 (მივლინებულები) და №3 (ცენტრალური აპარატი, პ.37–39); პ.20¹, 20² (ადმინისტრაციული მენეჯერი 75%, 2026), პ.19.
- ოჯახის წევრები თითო წესზე ცალკე უფლებით (მუხლი 4; მხარდაჭერის მიმღები, მეურვეობა/მზრუნველობა, ქვეყანაში ყოფნის პერიოდი).
- სრული თვე ან თარიღებით პერიოდი (არასრული თვე, შუა თვეში ქირის/ოჯახის ცვლილება).
- განათლება (690 EUR / 750 USD + სხვაობის 80%), დაზღვევა (წლიური ზღვარი ასაკის ჯგუფით), მაკლერი, ბარგი, პირველადი მოწყობა (დღიური ნორმა ხელით — №211 დადგენილება არ მოგვეწოდა), მგზავრობა, ავანსი, დამატებითი ხარჯები.
- **ქირისა და შეყვანილი განათლების ხარჯის შემდეგ დარჩენილი თანხა** — არა „ხელფასი“ და არა „ყველა ხარჯის შემდეგ“.
- **შედარება** — 5-მდე დაწესებულება ერთ ცხრილში (ვალუტები არ იკრიბება და არ კონვერტირდება).

თანხები ითვლება ზუსტი რაციონალური არითმეტიკით; მრგვალდება მხოლოდ ჩვენებისას (2 ათწილადი, half-up — ტექნიკური პოლიტიკა). ცარიელი ველი = „უცნობი“, `0` = ნამდვილი ნული.

## მონაცემები და წყაროები

- სამართლებრივი წყარო: `sources/original/rotation_sources.pdf` (ბრძანება + დანართები 1–10, სამუშაო ასლი 2026-10-28). წყაროების რეესტრი — `docs/source-manifest.json`.
- ნორმატიული მონაცემები (ერთადერთი წყარო აპისთვის): `src/data/normative-data.json` — 82 დაწესებულება (№5: 44 EUR, №6: 38 USD), 69 K/E სტრიქონი, 82 დაზღვევისა და 82 ბარგის ჩანაწერი.
- წესების რეესტრი: `docs/rules.md`; პუნქტების დაფარვა: `docs/coverage.md`; ღია საკითხები: `docs/open-questions.md`.
- ძველი კალკულატორის აუდიტი: `docs/legacy-audit.md` (მაგ. ირანის K 1.700 → 1.89, ოდესის დაზღვევა, ლიონის ბარგი, მაკლერის ფორმულა).

### ნორმების განახლება

1. ახალი რედაქციის PDF ჩადეთ `sources/original/`-ში და განაახლეთ `docs/source-manifest.json`.
2. `python3 -I scripts/extract-annexes.py && python3 -I scripts/extract-normative-data.py` → `sources/extracted/annex*.raw.json` და `src/data/normative-data.json`. ცხრილები ვიზუალურადაც გადაამოწმეთ (გაერთიანებული უჯრები, ათწილადი მძიმე).
3. `npm run validate:data`, `npm run test:golden`, `npm test`. ეტალონური მნიშვნელობები (`tests/fixtures/golden-cases.json`) იცვლება მხოლოდ წყაროდან ხელახლა გამოთვლით, არა კოდის შედეგის გადაწერით.
4. `docs/rules.md` შეცვლისას: `node scripts/gen-rule-catalog.mjs`.

### ბაზრის მონაცემები (ქირა, კომუნალური, სურსათი, რესტორნები)

- წყარო: Apify actor `automation-lab/numbeo-scraper` → Numbeo.com. გამოიძახება **მხოლოდ** Worker-იდან; ტოკენი — Cloudflare Secret `APIFY_TOKEN`.
- ქეში 30 დღე (Workers KV); ვერ მიღებისას ჩანს ბოლო შენახული ასლი „მოძველებულის“ ნიშნით.
- **ღირებულება (Apify, 2026-10-30):** $0.01 გაშვებაზე + $0.005 ქალაქზე. ყველა ქალაქის ინდექსები (547) ≈ $2.75 ერთ გაშვებაზე, ერთი ქალაქის ფასები ≈ $0.015. 30-დღიანი ქეშით ≈ $2.75/თვე + ≤ $1.22/თვე 81 ქალაქზე. ინდექსების გამორთვა: `"MARKET_RANKINGS_ENABLED": "false"`.
- სურსათის „კალათა“ = Numbeo-ს „Markets“ ერთეულების ფასების ჯამი ალკოჰოლისა და თამბაქოს გარეშე (არა თვიური ხარჯი).
- **რისკი:** Numbeo-ს გამოყენების პირობები კრძალავს ნებართვის გარეშე ავტომატურ ამოკითხვას და მონაცემის ხელახალ გავრცელებას; მესამე მხარის actor ამას არ ცვლის. საჭიროებისას გამორთვა: `wrangler.jsonc` → `"MARKET_PROVIDER": "off"`. დეტალები — `docs/providers.md`.
- ბაზრის მაჩვენებლები ბრძანების `K`-ს, `E`-ს, `H`-ს და თქვენს მიერ შეყვანილ ქირას **არ ცვლის**; ქირა გადადის გაანგარიშებაში მხოლოდ ღილაკით „გამოვიყენო დაგეგმილ ქირად“ (სცენარად).

## ტესტები

```bash
npm run validate:data   # ნორმატიული მონაცემების სქემა და მითითებები
npm run test:golden     # დამოუკიდებელი Python ეტალონები (Fraction), კოდის გარეშე
npm test                # unit + მონაცემები + პროვაიდერი + Worker
npm run build && npm run test:e2e   # ბრაუზერის ტესტები (Playwright/Chromium)
```

შედეგები და შეუსრულებელი შემოწმებები — `docs/test-report.md`.

## როგორ შეიქმნა

პროექტი ააწყო Claude Code-ის აგენტების გუნდმა: ხელმძღვანელი + ხუთი სპეციალისტი (სამართლებრივი ანალიტიკოსი, მონაცემებისა და გამოთვლების ინჟინერი, გარე მონაცემებისა და Cloudflare-ის ინჟინერი, ინტერფეისის ინჟინერი, დამოუკიდებელი შემმოწმებელი). ექსპერიმენტული Agent Teams ამ გარემოში ჩართული არ იყო, ამიტომ გამოყენებულია subagents (ცალკე აგენტები, რომლებსაც ხელმძღვანელი ეტაპობრივად ავალებდა და აგრძელებინებდა). ეტაპები და გადაწყვეტილებები — `docs/architecture.md`, `docs/contracts.md`.
